Vaultwarden's admin page (/admin) is where users, organisations, SMTP and the finer settings live. It opens with a token. The package made one at install and keeps it hashed in the container; if it's lost, make a new one here — it's shown once.

Admin token

Making a new token restarts Vaultwarden for a moment and signs the admin page out everywhere.
